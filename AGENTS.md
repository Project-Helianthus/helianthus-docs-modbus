# AGENTS

This repository is the public, protocol-native documentation home for
Helianthus Modbus integrations. Workspace orchestration is governed by the
workspace-root `AGENTS.md`.

1. Keep one issue and one pull request active at a time; use `issue/<id>-<slug>`.
2. Protocol pages define the public contract, not implementation provenance.
3. Do not publish credentials, serial numbers, private network coordinates,
   device fingerprints, raw private captures, or unsafe operation recipes.
4. Unknown fields and unqualified capabilities must remain explicitly unknown.
5. Run `./scripts/check_docs.sh` before publishing documentation changes.
